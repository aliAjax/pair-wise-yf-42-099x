动物园繁育配额账（许可证 · 配对建议 · 运输放行 · 外部对账）

身份：

1. 繁育许可证（一条 = 物种 + 年度 + 名额）

编号物种/年度名额有效期状态占用/排队/完成操作

2. 配对建议与批准（并发只一笔占名额，后来者排队；完成结果永久保留）

建议创建后为 proposed；在列表中对其执行“批准”。两人同时批准时由配额账串行化：有名额者占 slot，其余 queued。

到期/撤回/下调：未执行的批准与排队项自动失效（页面显示失效原因），已完成结果与运输放行保留。

配对许可证状态slot/位次失效原因操作

3. 运输放行（与批准分开记，保存许可证快照）

放行配对许可证快照机构状态

4. 外部登记回执对账（按编号去重 · 冲突留待处理 · 重试只续未完成）

回执许可证占用处理状态冲突原因操作

配额流水（可重放核对的账）

选择上方“台账”查看某许可证的流水。
